# Internacionalización (i18n)

## Configuración de vue-i18n

La internacionalización se configura en `src/boot/i18n.ts` usando **vue-i18n 11** con:

```typescript
const i18n = createI18n<{ message: MessageSchema }, MessageLanguages>({
  locale: 'es-ES',
  legacy: false,
  messages,
})
Quasar.lang.set(langEs)
```

- `locale`: español de España (`es-ES`)
- `legacy: false`: usa Composition API
- `Quasar.lang.set(langEs)`: traduce la UI de Quasar usando el pack español de `src/layouts/lang/es.ts`

Nota: `app.use(i18n)` está comentado en la implementación actual, lo que significa que i18n está configurado pero no completamente activo.

## Estructura de mensajes

```
src/i18n/
├── index.ts              # Exporta mensajes por locale
├── en-US/                # Traducciones inglés
│   ├── index.ts          # Mensajes globales
│   ├── common.ts         # Traducciones comunes
│   ├── user.ts           # Traducciones del módulo usuario
│   ├── role.ts           # Traducciones del módulo rol
│   └── permiso.ts        # Traducciones del módulo permiso
└── useActiveStore.ts     # Store activa de locale
```

**index.ts**:
```typescript
import enUS from './en-US'
export default { 'en-US': enUS }
```

**en-US/index.ts**:
```typescript
export default {
  failed: 'Action failed',
  success: 'Action was successful'
}
```

## Lazy loading

Los archivos de traducción se estructuran por módulo para facilitar carga perezosa. Los mensajes se importan estáticamente en `src/i18n/index.ts`, pero la arquitectura está preparada para carga dinámica cuando se necesiten más locales.

## Auto-import de traducciones

El plugin `@intlify/unplugin-vue-i18n` está en devDependencies y su configuración está comentada en `quasar.config.ts`. Cuando se active, compilará los archivos de `src/i18n/` para optimizar el bundle.

## Store de locale

`src/i18n/useActiveStore.ts` maneja el estado del locale activo. La store es auto-importada globalmente.

## Uso en componentes

```vue
<template>
  <div>{{ $t('success') }}</div>
</template>
<script setup lang="ts">
const { t } = useI18n()
console.log(t('success'))
</script>
```

## Traducciones de Quasar

El pack de idioma español se importa desde `src/layouts/lang/es.ts` y se aplica con `Quasar.lang.set(langEs)`. Esto traduce componentes Quasar como el paginador de `q-table`, etiquetas de diálogos, etc.
